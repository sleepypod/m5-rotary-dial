# Enclosure

A two-part bedside enclosure for the M5Stack Dial v1.1. It is also on [MakerWorld](https://makerworld.com/en/models/3365781-sleepypod-dial-enclosure-for-m5stack-dial), which is the easiest way to print it.

## Files

| File | What it is |
|---|---|
| `enclosure-base.3mf` | Bambu Studio project with both parts placed on one plate, with the print profile below. Open this if you have a Bambu printer. |
| `enclosure-faceplate.3mf` | The faceplate on its own, geometry only. Use it with any slicer. |

## Orientation

- **Base:** print on its rear face.
- **Faceplate:** print on its back face.

The project prints both parts in these orientations with supports off.

## Settings used

These come from the Bambu Studio project file.

| Setting | Value |
|---|---|
| Printer | Bambu Lab X1 Carbon |
| Nozzle | 0.2 mm |
| Layer height | 0.10 mm |
| Filament | Bambu PLA Matte |
| Walls | 4 |
| Infill | 15% grid |
| Supports | Off |
| Brim | Auto |
